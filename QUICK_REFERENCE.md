# Quick Reference Card - Harmonic Patterns

## 🎯 Pattern Recognition Cheat Sheet

### Gartley 222
```
Structure: M or W shape
AB: 61.8% of XA
BC: 38.2-88.6% of AB
CD: 113-161.8% of BC
AD: 78.6% of XA ★
Entry: At D (78.6% XA)
Stop: Below/above X
Target: Point A or beyond
```

### Bat
```
Structure: Tight M or W
AB: 38.2-50% of XA (shallow)
BC: 38.2-88.6% of AB
CD: 161.8-261.8% of BC (extended)
AD: 88.6% of XA ★★
Entry: At D (88.6% XA)
Stop: Below/above X
Target: Point A
```

### Butterfly
```
Structure: Extended M or W
AB: 78.6% of XA
BC: 38.2-88.6% of AB
CD: 161.8-224% of BC
AD: 127-161.8% of XA ★★★
Entry: At D (127-161.8% XA) - D BEYOND X
Stop: 2 ATR beyond X
Target: Point A, then C
```

### Crab
```
Structure: Extreme extension
AB: 38.2-61.8% of XA
BC: 38.2-88.6% of AB
CD: 224-361.8% of BC (extreme)
AD: 161.8% of XA ★★★★
Entry: At D (161.8% XA) - D FAR BEYOND X
Stop: 2-3 ATR beyond X
Target: Point C, then A
```

### Shark
```
Structure: C beyond A (unique)

AD: 88.6-113% of XA ★★

```

### Cypher

AD: 78.6% of XA ★★★

     /\          /\

   /    \      /    \
  X      B    D

D is below A (except Butterfly/Crab where D below X)
Enter at D, target moves toward A

## 📊 Entry Checklist

### Before Entry
- [ ] Pattern quality score ≥ 75%
- [ ] D-point clearly defined (pivot confirmed)
- [ ] Trend filter aligned (reversal setup)
- [ ] ICT confluence present (FVG or OB)
- [ ] Volume surge or above average
- [ ] Key support/resistance near D
- [ ] Risk/reward ≥ 1:2
- [ ] Stop loss placement clear

### Entry Methods

**Conservative (Recommended)**
1. Wait for D-point pivot confirmation
2. Wait for bullish/bearish price action (engulfing, pin bar)
3. Enter on retest of D-point
4. Stop: 1-2 ATR beyond X
5. Win rate: ~70% | R:R: 1:2.5+

**Moderate**
1. Enter immediately at D-point completion
2. Confirmation: Strong volume + ICT confluence
3. Stop: Just beyond D (tight)
4. Win rate: ~60% | R:R: 1:2

**Aggressive (Advanced Only)**
1. Enter at projected D-point (before pivot confirms)
2. Use limit order at perfect Fibonacci level
3. Very tight stop (10-20 pips beyond D)
4. Win rate: ~50% | R:R: 1:3+

## ⚠️ Risk Management Rules

### Position Sizing
```
Account Risk: 1-2% per trade
Stop Loss: 1-2 ATR or beyond X-point

Example:
Account: $10,000
Risk: 1.5% = $150
Stop: 50 pips
Position Size: $150 / 50 pips = $3 per pip
```

### Max Drawdown Rules
```
Daily Loss Limit: 3% of account → Stop trading for the day
Weekly Loss Limit: 6% of account → Review strategy
Monthly Loss: 10% → Reduce position size by 50%
```

### Pattern Limits
```
Max simultaneous patterns: 3
Max per pattern type per day: 2
Skip pattern if similar failed in last 24h
```

## 🚦 Quality Filters

### Pattern Score Interpretation
```
90-100%: EXCELLENT → Full position size
80-89%:  GREAT → Standard position
75-79%:  GOOD → Reduce position 50%
70-74%:  ACCEPTABLE → Reduce position 70% or skip
<70%:    SKIP
```

### ICT Confluence Scoring
```
Pattern + FVG + OB + Volume = PREMIUM (4/4) ★★★★
Pattern + FVG + OB = GREAT (3/4) ★★★
Pattern + FVG OR OB = GOOD (2/4) ★★
Pattern only = SKIP (1/4) ★
```

## 🔥 Common Mistakes

### ❌ Don't Do This
- Trade patterns with <75% score
- Ignore trend filter (trade with trend)
- Enter before D-point confirmation
- No stop loss
- Risk >2% per trade
- Chase missed entries
- Revenge trade after loss
- Ignore ICT confluence

### ✅ Do This
- Wait for high-quality setups
- Use trend filter for reversals only
- Confirm D-point pivot
- Always set stop loss BEFORE entry
- Risk 1-2% max
- Let missed entries go
- Follow your trading plan
- Look for confluence

## 🧠 Mental Checklist

Before every trade ask:
1. **"Is this pattern quality ≥75%?"** → If no, skip
2. **"Do I have confluence?"** → If no, be cautious
3. **"Am I risking 1-2% only?"** → If no, adjust
4. **"Can I accept the loss?"** → If no, don't trade
5. **"Is this part of my plan?"** → If no, skip
